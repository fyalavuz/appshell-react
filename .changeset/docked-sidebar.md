Add a docked Sidebar variant: `<Sidebar variant="docked">` renders a persistent panel that sticks below the Header, optionally collapses to an icon rail (`collapsible`, `collapsed`/`defaultCollapsed`/`onCollapsedChange`, `width`/`railWidth`), and automatically degrades to the existing overlay drawer below a breakpoint (`breakpoint="sm" | "md" | "lg" | "none"`). AppShell now hoists a docked Sidebar child into a two-column layout automatically. NavItem and NavGroup gained icon-rail styling (labels hide, `title` tooltips) driven by the sidebar's collapsed state. The default overlay variant is unchanged; `SidebarProps` is now a discriminated union (`SidebarOverlayProps | SidebarDockedProps`, both exported). `useAppShell().scrollDirection` now reports the real scroll direction instead of always `null`. The dead `"./styles.css"` package export (the file was never built) was removed. Also fixed: `useSafeArea`'s env() fallback never resolved (env() cannot be read via getPropertyValue) — insets are now measured with a probe element. New: `SearchField` component for the Header's search row — `variant="pill"` (rounded) or `variant="full"` (edge-to-edge), theme-aware via `useHeaderTheme`, controlled/uncontrolled with `onSubmit`. Fixed: built chunks now ship the `"use client"` directive (tsup/rollup stripped it), so the published package works inside Next.js App Router server components; a Node-environment `renderToString` smoke test now guards full SSR compatibility.

New components — all standalone, customizable, replaceable: `SearchModal` (a full search overlay — sheet on phones, centered palette on desktop — with its own input, render-prop results, Escape/backdrop dismissal, scroll lock and focus restore; seed it from a trigger via `defaultQuery`), `UserMenu`/`UserMenuItem` (avatar trigger + account dropdown with identity header, custom `trigger`, controlled or uncontrolled, header-theme aware) and `Avatar` (image-or-initials identity mark). `SearchField` gained `onFocus`/`onClick` passthroughs to act as a SearchModal trigger. `Sidebar` gained `bottomContent` — a slot pinned below the scrolling nav in both the docked panel and the drawer, for settings/about/theme-toggle/user-menu rows.

Safe areas now standardize on the platform's `env(safe-area-inset-*)` (Apple + Android, `viewport-fit=cover` required) as the single source of truth. The simulation override variables were renamed from `--sa-*` to the clearly-scoped `--appshell-safe-area-inset-*` — they exist only for mockups, Storybook and tests. `SafeArea` now renders its padding as SSR-safe inline styles instead of a client-side effect.
